
This chall was a Server-Side Template Injection (SSTI) in Jinja2, but with aggressive input sanitization.

These keywords were blocked 
```python
BLOCKED_LITERALS = [
  '{', '}', '__', 'open', 'os', 'subprocess', 'import', 'eval', 'exec',
  'system', 'popen', 'builtins', 'globals', 'locals', 'getattr', 'setattr',
  'class', 'compile', 'inspect'
]
```


The blocklist checked for literal `{` and `}` characters, so we URL-encoded them as 
- `{` → `%7B`
- `}` → `%7D`


Since the filter checked strings AFTER URL decoding, we used Python's slice notation `[::-1]` to reverse strings at runtime:
- `'slabolg'[::-1]` → `'globals'`
- `'snitliub'[::-1]` → `'builtins'`
- `'tropmi'[::-1]` → `'import'`
- `'nepop'[::-1]` → `'popen'`
- `'nepo'[::-1]` → `'open'`


Used `\x5f` instead of `_` to bypass the `__` filter:
- `\x5f\x5f` → `__`
